# Data Field Inventory

This inventory was produced for
[GitHub issue #208](https://github.com/stevekinney/tribunal/issues/208) against
`origin/main` at `4c0016dec87cd6c9da4066a9a968fc18e72315f3` and refreshed
against `90771b27fe9c8e2e94a3e0ad69c1d71ef870f7f9`. The refresh accounts for
the deleted `user_api_key` surface from #250, dashboard summary additions from
#222, the removed action-item dependency table from #251, and the
non-check-suite webhook handler trace from #239. This inventory applies the
issue's field test: if changing a field never changes a query, display,
decision, or audit output, the field is dead data.

## Scope

Included:

- Every exported Drizzle table and column from `packages/database/src/schema/index.ts`.
- Material cross-package response and port shapes that flow between workspaces:
  `@tribunal/github`, `@tribunal/review-core`, `@tribunal/cost`,
  `@tribunal/sandbox`, `applications/engine`, and `applications/web`.
- Query return shapes in `packages/database/src/queries` and
  `applications/web/src/lib/server/webhook-events.ts` when they are consumed by
  another workspace or a Svelte route.

Excluded as already handled by the issue:

- `user_review_settings.default_model` in
  `packages/database/src/schema/user-review-settings.ts`: marked below as
  excluded; the settings matrix already verifies it is now read by the engine.
- `DashboardUnavailableReason` in `packages/github/src/dashboard/types.ts`:
  marked below as excluded; the issue says not to re-investigate it.
- The discarded caught error in `applications/web/src/hooks.server.ts`: not a
  database or cross-package response field, and explicitly excluded by the issue.
- The former `user_api_key` table and API-key validation surface: issue #233 is
  already closed as completed on the refreshed base.
- The former `pull_request_action_item_dependency` table: issue #234 is already
  closed as completed on the refreshed base.

Classification meanings:

- **decision**: code branches, filters, claims, deduplicates, joins, or calls an
  external API based on the field.
- **display**: rendered or returned to a user-facing route/API response.
- **observability**: retained for run inspection, audit, logs, debugging, or
  operational traceability.
- **test-only**: only tests, factories, validation tests, or schema invariant
  tests use the field.
- **none**: no current producer/reader pair, or a write/default exists but no
  downstream reader changes behavior, display, or observability.

  `cost_event.id`, `kind`, and `agent_run_id` are written without current

  claimable listener-delivery query fields are returned without current readers.
- [#262](https://github.com/stevekinney/tribunal/issues/262):
